Privacy policy

Last updated: November 5, 2026

CleanCut is a browser extension. This page explains exactly what data it handles. The short version: it works from files it downloads and from your own device, and sends nothing about you to us. There is no CleanCut server and no account. We don't sell data, show ads, or build profiles.

What stays on your device

  • Subtitles. The extension reads the subtitle file the video player uses and analyzes it locally to find profanity and scene hints. Subtitle text is never sent to us or to anyone else.
  • Audio, if you turn on Listen ahead. For videos without captions, on sites that don't encrypt their audio (YouTube, Vimeo and the like; never Netflix, Prime Video, Disney+ or other DRM services), the extension can transcribe the audio the player has already downloaded, with a speech recognition model that runs on your computer, to find profanity before it plays. The audio and the transcript are never sent anywhere and are not kept: they're held in memory only while the video plays. It is off until you turn it on.
  • Your settings (chosen rating, per-category choices, actions, timing adjustments). These live in the browser's extension storage. If you're signed in to Chrome with sync turned on, the browser may sync them across your devices as it does for any extension.
  • Your own flags and a cache of recently used catalog files are stored locally in the extension.
  • An optional debug log is off unless you tick Record a debug log in the popup. It stays in your browser, is never sent automatically, and is saved to a file only if you click Save debug log.

What the extension downloads, and from where

  • The community catalog is a public set of files in a GitHub repository (fabioelia/play-it-all), read through raw.githubusercontent.com. The extension downloads a small index (it asks only whether it has changed), and then only the file for a title that appears in it. Titles the catalog doesn't know cost no further request.
  • Those requests are made to GitHub, which is the host of the files. GitHub can see your IP address, the file requested (which reveals the title) and standard browser details, as with any web request. We don't receive these requests. GitHub's own privacy statement applies to them.
  • Subtitle files are fetched from the streaming site you're already using (the same file the player loads) to analyze locally.
  • If you point CleanCut at a different catalog address in Options, requests go to that host instead.
  • The speech model (about 44 MB), only if you turn on Listen ahead and agree to the download. It is downloaded once from Hugging Face (huggingface.co and its file servers), checked against fixed checksums, and kept in the extension's storage; you can delete it in Options. Hugging Face sees your IP address and which model files were requested, as with any download; it doesn't see what you watch.
  • The extension never uploads the title you watch, your viewing history, your account on any streaming site, or subtitles.

If you choose to contribute

Sharing is always your explicit action. Share on GitHub opens a pre-filled GitHub issue; nothing is submitted until you submit it on GitHub. Contributions are public, including the title, timestamps, any note you write, and your GitHub username (GitHub's own policies cover your GitHub account). You can ask us to remove a contribution at any time (see Support).

What we do not do

  • We don't sell or rent data, and we don't share it with advertisers or data brokers.
  • We don't use data for creditworthiness, lending, or any purpose unrelated to CleanCut's single purpose of filtering scenes.
  • We don't load or run remotely hosted code. All extension code ships inside the extension package.

Permissions the extension asks for

  • Access to the supported streaming sites (Netflix, Prime Video, YouTube, Disney+, HBO Max, Hulu, Apple TV, Paramount+, Peacock, Crunchyroll, Tubi, Pluto TV, The Roku Channel, Plex, Vimeo): to detect what's playing, read its subtitle track, and skip, mute or hide the player.
  • Access to raw.githubusercontent.com: to read the community catalog.
  • storage: to save your settings and flags.
  • offscreen: used only when Listen ahead is on, to run the speech model in the extension's own background page instead of on the video's page. No extra site access is needed for the model download.
  • activeTab / scripting: so CleanCut can run on a page when you click its toolbar button, and so the popup can control the current tab's player.
  • Optional access to other sites: asked for at the moment you choose to use a custom catalog address, or to use CleanCut on another page. You can decline.

Your choices

  • Uninstalling the extension removes everything stored on your device.
  • To remove something you contributed, open an issue (see Contact below) and we'll delete it from the catalog. Git history keeps old versions; we can ask GitHub to purge personal data on request.
  • You can turn the extension off at any time from its popup.

Children

CleanCut is designed to help families. It is operated for adults and doesn't knowingly collect personal information from children under 13. There are no accounts. Contributions are public on GitHub, so please don't include personal details in notes.

Changes

If this policy changes materially, we'll update the date above and note it in the extension's release notes.

Contact

Open an issue at github.com/fabioelia/play-it-all/issues. Please don't include personal details in a public issue; if you need to share something private, say so in the issue and we'll arrange a way.
